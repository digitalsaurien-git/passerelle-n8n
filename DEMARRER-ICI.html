Installer Passerelle IA

Ce guide permet d’abord de tester l’application sans IA, puis de vérifier la liaison avec n8n, et enfin d’activer OpenAI et Claude.

Ordre conseillé : Coolify en mode démonstration → workflow de test n8n → workflow OpenAI/Claude. Ainsi, chaque problème éventuel est facile à localiser.

1. Mettre le dossier dans un dépôt Git

  1. Décompressez le kit.
  2. Créez un dépôt GitHub privé, par exemple passerelle-ia.
  3. Placez le contenu du dossier Passerelle-IA à la racine puis envoyez-le sur GitHub. N’ajoutez jamais un fichier .env avec de vrais secrets.

2. Créer l’application dans Coolify

  1. Dans votre projet Coolify, cliquez sur New Resource puis choisissez votre dépôt Git privé.
  2. Choisissez le déploiement Docker Compose. Le fichier détecté est compose.yaml.
  3. Le service public s’appelle passerelle et écoute sur le port interne 8000.
  4. Ajoutez un stockage persistant si Coolify ne reprend pas automatiquement le volume nommé passerelle-data, monté sur /data.

3. Ajouter les variables

VariableValeur au premier test
APP_PASSWORDUn mot de passe unique d’au moins 16 caractères
APP_MODEdemo
ALLOWED_ORIGINSLes deux URL HTTPS exactes, séparées par une virgule, sans barre finale
N8N_WEBHOOK_URLlaisser vide
N8N_WEBHOOK_TOKENlaisser vide

Déployez. Ouvrez l’adresse, connectez-vous, créez une conversation, essayez OpenAI puis Claude, joignez un fichier et rechargez la page. En mode démonstration, la réponse confirme les informations reçues sans consommer d’IA.

4. Ajouter les deux adresses

  1. Pour le domaine personnalisé, créez par exemple assistant.votre-domaine.net. Dans votre gestion DNS, son enregistrement A pointe vers l’IP publique du serveur. Ajoutez ensuite cette URL dans les domaines Coolify.
  2. Pour l’adresse de secours, utilisez le domaine sslip.io généré par Coolify à partir de l’IP du serveur. Coolify permet d’ajouter plusieurs domaines au même service.
  3. Attendez que les deux certificats HTTPS soient valides.
  4. Recopiez les deux URL exactes dans ALLOWED_ORIGINS, puis redéployez.
La dictée du navigateur exige HTTPS et l’autorisation du microphone. Certains réseaux d’entreprise bloquent le service de reconnaissance vocale du navigateur. Le bouton affichera une erreur claire dans ce cas.

5. Tester la liaison n8n sans IA

  1. Dans n8n, importez n8n/01-Test-liaison-n8n.json.
  2. Créez un identifiant Header Auth : nom X-Webhook-Token, valeur aléatoire longue.
  3. Sélectionnez cet identifiant dans le nœud Entree application.
  4. Activez/publiez le workflow et copiez sa Production URL.
  5. Dans Coolify, mettez APP_MODE=n8n, la Production URL dans N8N_WEBHOOK_URL et la valeur secrète dans N8N_WEBHOOK_TOKEN. Redéployez.
  6. Envoyez un message depuis l’application. La réponse doit commencer par « TEST N8N RÉUSSI ».

6. Activer OpenAI et Claude

  1. Importez n8n/02-Assistant-IA-OpenAI-Claude.json.
  2. Sur son Webhook, utilisez le même Header Auth X-Webhook-Token.
  3. Dans Appeler OpenAI, créez un autre Header Auth : nom Authorization, valeur Bearer VOTRE_CLE_OPENAI.
  4. Dans Appeler Claude, créez un Header Auth : nom x-api-key, valeur égale à votre clé Anthropic.
  5. Activez ce workflow, copiez sa Production URL et remplacez uniquement N8N_WEBHOOK_URL dans Coolify.
  6. Testez une question avec OpenAI, puis une avec Claude dans la même conversation.
À savoir : les abonnements aux sites ChatGPT et Claude et la consommation API sont généralement facturés séparément. Si vous ne possédez pas de clés API, vérifiez si votre n8n propose des crédits de passerelle IA et remplacez les deux nœuds HTTP par les nœuds de modèles correspondants.

7. Relier votre agent maître existant

Le fichier ARCHITECTURE-MULTI-ENTREES.md explique comment réunir Telegram, le Webhook de l’application et l’arrivée de mails, puis répondre sur le bon canal. Pour éviter de recopier toute votre batterie d’agents, placez le cœur « agent maître + sous-agents » dans un sous-workflow appelé par les trois entrées.

8. Sauvegarde et mise à jour

Sauvegardez régulièrement le volume contenant /data. Il renferme la base SQLite et toutes les pièces jointes. Une mise à jour du conteneur conserve le volume. Une suppression du volume efface l’historique.
